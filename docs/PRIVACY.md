# Privacy

FanControl is designed to be local-first.

- It does not require an account.
- It does not include analytics, crash reporting, advertising, or a network
  service.
- It reads local temperature and fan values through macOS SMC interfaces.
- It stores its presets, preferences, and optional local service log in
  `~/.config/fancontrol/`.

The repository must not contain exported configuration, logs, screenshots with
personal information, secrets, or device serial numbers. See
[CONTRIBUTING.md](../CONTRIBUTING.md) before attaching diagnostic material.

This statement describes the released source and app. Third-party sites used to
download a release (for example, GitHub) have their own privacy practices.
