# Changelog

All notable public changes will be documented here.

## [0.1.0-preview] - 2026-08-13

Initial public-source preview maintained by gmaxio.

- Focused project positioning on Apple Silicon Macs with physical fans.
- Added English and Chinese documentation, hardware compatibility boundaries,
  privacy and security policies, contribution guidance, and issue templates.
- Restricted non-zero target RPM writes to hardware-reported min/max values.
- Added source-only repository hygiene and repeatable universal app packaging.
- Established GPL-2.0-or-later licensing and upstream attribution.
- Published optional ad-hoc signed learning/test archives with checksum and
  per-app Gatekeeper guidance; no notarization claim is made.

[0.1.0-preview]: https://github.com/gmaxio/fancontrol/releases/tag/v0.1.0-preview
